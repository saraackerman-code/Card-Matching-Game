Card Matching Game
A browser‑based memory game where players flip cards to find matching pairs. The game includes multiple board sizes, a shuffle mechanic, click tracking, win/loss conditions, and animated card flips.

Features
Three board sizes: 2×4, 4×4, 6×4

Shuffle system to randomize card positions

Flip animation using CSS 3D transforms

Click counter and pair counter

Win/Loss modals with restart buttons

Responsive layout centered on the page

How to Play
Select a board size.

Press Shuffle to randomize the cards.

Press Start to begin the game.

Click cards to flip them and find matching pairs.

Win by matching all pairs before reaching the click limit.
